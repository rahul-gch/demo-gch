# Graph Central Hub

Improve the dashboard so the ecosystem graph is clearly the visual center of the product.

Make the graph section larger and more important than KPI cards.

Add small connected insight panels around the graph:

- Confidence gap

- Missing evidence

- Highest risk node

- Best future matchmaking opportunity

Make KPIs feel like outputs produced by the graph, not separate dashboard metrics.

Add a small label above KPI cards:

“Intelligence outputs generated from the ecosystem graph”
